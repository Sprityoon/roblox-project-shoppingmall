# T-127 알바 숙련도 ("직업")

선행: T-116(알바), T-105(상점과 아이템).

## 목적

알바를 "돈 버는 반복 작업"에서 **"내 직업"**으로 바꾼다. 알바마다 숙련도 단계가 있고, 단계가 오르면 그 일의 명찰(칭호)과 유니폼이 열린다. 오래 한 사람은 티가 나고(성장), 어떤 유니폼을 입을지 고르며(역할), 남에게 보인다(표현). 근거: design-details.md 20번.

## 지금 상태 (선행 카드가 끝난 뒤)

- `JobService`가 알바를 마칠 때마다 `stats.jobsDone`, `stats.stockDone` 또는 `stats.deliveryDone`을 1씩 올린다.
- `DataService:GrantItem`, `SetEquipped`가 있고 `CosmeticService`가 장착한 꾸미기를 캐릭터에 붙인다.
- 품목 표 `Config.ShopItems`에는 `notForSale = true`인 보상용 품목을 둘 수 있다.

## 만들 것

| 경로 | 할 일 |
|---|---|
| `Shared.Config.JobRanks` (신규) | 직업별 단계 기준, 보상, 문구 |
| `Shared.Types` | `ItemCategory`에 `"uniform"` 추가 |
| `Shared.Config.ShopItems` | 보상용 품목(칭호 8개, 유니폼 4개. 모두 `notForSale = true`) |
| `Server.Services.JobService` | 알바를 마칠 때 단계 계산, 단계가 오르면 보상 지급. 단계별 추가 코인 |
| `Server.Services.CosmeticService` | `uniform` 분류 표시 |
| `Client.Screens.ShopScreen` | "내 직업" 탭 추가(아래) |

## 직업과 단계

직업 2개: **마트 직원**(진열, `stockDone`), **배달원**(쇼핑백 배달, `deliveryDone`). 단계는 저장하지 않고 횟수에서 계산한다.

| 단계 | 이름 | 누적 횟수 | 열리는 것 | 건당 추가 코인 |
|---|---|---|---|---|
| 1 | 수습 | 0 | 없음 | 0 |
| 2 | 정직원 | 15 | 칭호 "마트 정직원" / "배달 정직원" | 0 |
| 3 | 숙련 | 50 | 유니폼: 마트 앞치마(주황) / 배달 조끼(하늘) | +1 |
| 4 | 베테랑 | 150 | 칭호 "마트 베테랑" / "배달 베테랑" | +1 |
| 5 | 달인 | 400 | 금색 유니폼 + 칭호 "진열의 달인" / "배달의 달인" | +2 |

- 한 건이 20초쯤이므로 정직원은 첫 접속 5분, 숙련은 약 17분, 달인은 2시간 남짓이다.
- 보상은 단계에 도달한 순간 `GrantItem`으로 준다. 이미 기준을 넘긴 사람도 다음 알바를 마칠 때 빠진 보상을 채워 준다(중복 지급은 `OwnsItem`으로 막는다). 자동 장착은 하지 않는다.
- 유니폼은 상점 NPC가 입은 것과 같은 방식이다: 몸통에 용접한 얇은 파트(앞치마 가슴판, 치마, 주머니 / 조끼). `Massless`, `CanCollide/CanQuery/CanTouch = false`. 직원 NPC의 앞치마 구조는 `Workspace.Mall.NPCs.mart_npc.Character`의 `ApronBib`, `ApronSkirt`, `ApronPocket`을 참고한다.
- 유니폼은 풍선·발자취 등 다른 분류와 함께 달 수 있다(분류마다 하나).

## 화면과 알림

- **알바를 마칠 때의 토스트**에 진행도를 붙인다: "진열 완료 +5 · 정직원까지 3건". 마지막 단계면 횟수만: "진열 완료 +7 · 412건째".
- **단계가 오를 때**: 눈에 띄는 토스트("마트 정직원이 됐어요! 칭호를 받았어요")와 캐릭터 주위의 짧은 반짝임(1.5초, 다른 사람에게도 보인다).
- **상점 화면에 "내 직업" 탭**: 직업 2개의 현재 단계, 다음 단계까지 남은 횟수(진행 막대), 단계별 보상 목록(받은 것은 장착/해제 버튼, 못 받은 것은 잠금 표시와 필요한 횟수). 어느 상점 NPC로 열어도 보인다.
- `roblox-ui-ux` 스킬을 먼저 읽고, `ShopScreen`의 카드와 버튼 구성을 그대로 재사용한다.

## 건드리지 않는 것

- 알바의 동작과 기본 보상(T-116의 수치).
- 판매 품목과 가격.

## 확인 방법

단계 기준을 시험할 때만 잠시 줄였다가(예: 2 / 4 / 6 / 8) 반드시 되돌린다.

1. 진열 2건째에 정직원 토스트와 반짝임, 보유 목록에 칭호가 생기는지. 상점의 판매 목록에는 나오지 않는지.
2. "내 직업" 탭에 단계와 남은 횟수가 맞게 보이는지. PC와 휴대폰 가로 캡처.
3. 유니폼을 장착하면 캐릭터에 붙고, 리셋해도 유지되고, 풍선과 함께 달리는지(캡처).
4. 3단계부터 건당 코인이 +1 되는지(진열 5 → 6).
5. 배달 횟수는 마트 직원 단계에 영향을 주지 않는지.
6. 기준을 원래 값으로 되돌렸는지 Config를 다시 읽어 확인.
7. 콘솔 오류가 없는지.

## 물어볼 것

- 유니폼이 풍선·칭호와 겹쳐 보기 나쁘면 위치를 조정하고 캡처와 함께 보고한다.
