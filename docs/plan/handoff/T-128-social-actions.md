# T-128 말 없이 하는 교류

선행: T-116(알바), T-105(상점과 아이템), T-106(이모트. 완료).

## 목적

어린 이용자는 채팅을 못 쓰는 경우가 많다. **말 없이 서로에게 할 수 있는 행동**을 넣어 "옆에 사람이 있어서 좋다"를 만든다. 세 가지: 같이 일하면 보너스, 간식 나눠 주기, 하이파이브. 근거: design-details.md 20번.

## 지금 상태 (선행 카드가 끝난 뒤)

- `JobService`: 알바를 마치면 코인을 준다. `CarryService:GetCarried(player)`로 누가 무엇을 들고 있는지 알 수 있다.
- `ShopService`: `ShopRequest("buy", itemId)`. 간식은 사는 즉시 본인에게 효과가 걸린다(`CosmeticService`).
- 이모트: `HudController`의 이모트 버튼이 클라이언트에서 애니메이션을 재생한다. **서버는 누가 어떤 이모트를 했는지 모른다.** 종류는 `Config.Emotes`의 4종.

## 1. 같이 일하기 보너스

- 알바 물건을 놓는 순간, 반경 `BuddyRadius = 25` studs 안에 **알바 물건(`box` 또는 `bag`)을 들고 있는 다른 플레이어**가 있으면 코인 `BuddyBonus = 1`을 더 받는다.
- 토스트에 붙인다: "진열 완료 +5 · 함께 일하기 +1".
- 상대는 자기 물건을 놓을 때 같은 조건으로 따로 받는다. 서로 주고받는 것이 아니라 "옆에서 같이 일하면 둘 다 조금 더 번다"이다.
- T-116의 최소 시간 검사에 걸린 배달에는 붙지 않는다.

## 2. 나눠 먹는 간식

- 마트에 품목 3개 추가(분류 `consumable`, 필드 `share = true`): 에너지 젤리 세트(60), 점프 사탕 세트(60), 반짝 음료 세트(40). 효과는 낱개와 같다.
- 사면 **본인과 반경 `ShareRadius = 15` studs 안의 모든 플레이어**에게 효과가 걸린다.
- 받은 사람에게 토스트: "○○님이 에너지 젤리를 나눠 줬어요!"(○○는 `DisplayName`). 산 사람에게: "3명과 나눠 먹었어요!"(0명이면 "혼자 먹었어요. 다음엔 친구 옆에서!").
- 산 사람의 `stats.treatsGiven`을 받은 사람 수(본인 제외)만큼 올린다. 누적 10명이 되면 칭호 "인심왕"(`notForSale`)을 준다.
- 상점 화면에서는 낱개 옆에 세트 카드가 따로 보인다. 받는 사람을 고르는 화면은 만들지 않는다.

## 3. 하이파이브

- 두 플레이어가 `HighFiveRadius = 8` studs 안에서 `HighFiveWindowSeconds = 3`초 안에 **같은 이모트**를 하면 하이파이브다.
- 두 사람 사이 중간 지점에 짧은 별 반짝임(1초, 모두에게 보인다)과 두 사람에게 토스트 "○○님과 하이파이브!".
- 보상: 한 번 접속해 있는 동안 **서로 다른 상대 `HighFivePaidPartners = 5`명까지** 각각 `HighFiveCoins = 3`. 같은 상대와 다시 하면 효과만 나온다. 접속 중에만 기억한다(저장하지 않는다).
- 같은 쌍의 하이파이브는 `HighFiveCooldownSeconds = 10`초에 한 번만 판정한다(효과 도배 방지).
- `stats.highFives`를 올린다(나중에 업적에 쓴다).

**EmotePlayed 검사**: 인자가 문자열이고 `Config.Emotes`에 있는 id인지, 호출 빈도(`Util.RateLimiter`, 초당 2회 안팎), 캐릭터가 살아 있는지. 서버는 이 신호를 하이파이브 판정에만 쓰고 애니메이션은 건드리지 않는다.

## 건드리지 않는 것

- 이모트 버튼의 모양과 배치.
- 채팅. 친구 초대, 거래, 코인 주고받기는 만들지 않는다(악용 여지가 크다).

## 확인 방법

대부분 2명이 필요하다. Studio의 "테스트 > 로컬 서버(2인)"는 MCP로 시작할 수 없을 수 있다. 못 하면 못 했다고 적고, 가능한 범위는 서버에서 조건을 만들어 확인한다.

1. (1인) 주변에 아무도 없으면 보너스가 붙지 않는지.
2. (1인) 세트 간식을 사면 본인에게 효과가 걸리고 "혼자 먹었어요" 토스트가 뜨는지. 코인이 60 줄어드는지.
3. (1인) `EmotePlayed`에 잘못된 값(숫자, 없는 id, 연타)을 보내도 오류 없이 무시되는지.
4. (2인 또는 서버에서 가짜 조건) 같이 일하기 +1, 간식 나눔의 효과와 토스트, `treatsGiven` 증가, 하이파이브의 효과·코인·상대 5명 제한·10초 간격.
5. 2인 확인을 못 했으면 사용자에게 2인 테스트 항목으로 넘긴다(무엇을 봐야 하는지 목록으로).
6. 콘솔 오류가 없는지.

## 물어볼 것

- 없음.
