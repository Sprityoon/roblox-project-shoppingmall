# T-117 첫 접속 흐름

선행: T-116(알바), T-105(상점과 아이템).

## 목적

처음 들어온 사람이 설명 창 없이 5분 안에 **선물을 받고 → 알바를 한 번 하고 → 소동과 상점을 알게** 한다. 긴 글은 띄우지 않고, 지금 할 것 하나만 가리킨다. 근거: design-details.md 11번.

## 만들 것

| 경로 | 할 일 |
|---|---|
| `Shared.Config.Onboarding` (신규) | 단계, 문구, 거리, 보상 아이템 id |
| `Shared.Config.ShopItems` | 환영 풍선 `balloon_welcome`(민트색, `notForSale = true`) 추가 |
| `Server.Services.OnboardingService` (신규) | 단계 진행과 선물 지급 |
| `Client.Controllers.GuideController` (신규) | 가리키는 표시(바닥 안내선, 목표 표식) |

## 단계

진행 단계는 프로필의 `stats.onboardingStep`(숫자)에 저장하고, Player 속성 `OnboardingStep`으로 복제한다. 한 번 끝낸 사람에게는 다시 나오지 않는다.

| 단계 | 화면에 보이는 것 | 넘어가는 조건 | 넘어갈 때 |
|---|---|---|---|
| 0 | 몰 안내원(`guide_npc`) 머리 위 표식 + 내 발밑에서 안내원까지 바닥 안내선. 토스트 "안내원에게 가 보세요" | 안내원 10 studs 안에 들어감(서버가 거리 확인) | 환영 풍선 지급·장착, 토스트 "환영 선물: 풍선!" |
| 1 | 창고의 상자 자리까지 바닥 안내선. 토스트 "창고에서 상자를 들어 마트 진열대에 놓아 보세요" | 상자를 듦(`Carrying == "box"`) | 안내선이 마트의 빈 칸 쪽으로 바뀜 |
| 2 | 마트의 빈 진열 칸까지 안내선 | 진열 1회 완료(`stats.jobsDone ≥ 1`) | 토스트 "잘했어요! 소동 알림이 뜨면 광장으로 모여요" |
| 3 | 안내 표시 없음 | 소동에 한 번 참여(`stats.eventsJoined ≥ 1`) | 토스트 "코인이 모였어요. 상점에서 꾸며 보세요" |
| 4 | 끝 | | |

- 단계 1~2 도중에 소동 공지가 뜨면 안내선을 숨기고, 소동이 끝나 `idle`이 되면 다시 보여 준다.
- 쇼핑백 배달로 첫 알바를 해도 단계 2를 통과한 것으로 친다(`jobsDone ≥ 1`).

## 가리키는 표시

- **바닥 안내선**: 내 캐릭터 발밑과 목표 지점을 잇는 `Beam`(클라이언트에서만 만든다. 다른 사람에게는 보이지 않는다). 색은 `Theme`의 강조색, 폭 1.5 studs 안팎, 천천히 흐르는 무늬. 벽을 뚫고 직선으로 이어져도 된다(방향만 알려 주면 충분하다).
- **목표 표식**: 목표 위에 떠서 천천히 오르내리는 화살표 모양 파트(클라이언트에서만). 목표 5 studs 안에 들어오면 숨긴다.
- `roblox-ui-ux` 스킬의 모션 규칙을 따른다(`GuiService.ReducedMotionEnabled`면 움직임을 줄인다).

## 건드리지 않는 것

- 기존 HUD 배치. 새 창이나 모달을 만들지 않는다.
- 알바와 상점의 로직.

## 확인 방법

Studio는 저장이 꺼져 있어 접속할 때마다 단계 0부터 시작한다(시험하기에는 편하다).

1. 접속 직후 안내원 쪽으로 안내선과 표식이 보이는지(캡처).
2. 안내원에게 다가가면 풍선이 달리고 토스트가 뜨는지. 상점 화면의 풍선 목록에 환영 풍선이 **나오지 않는지**, 보유 목록에는 있는지.
3. 상자를 들면 안내선이 마트 쪽으로 바뀌는지. 진열하면 단계 2가 끝나고 안내선이 사라지는지.
4. 소동을 강제로 시작해 한 번 참여하면 상점 안내 토스트가 뜨는지.
5. 단계 4 뒤에 캐릭터를 리셋해도 안내가 다시 나오지 않는지.
6. 단계 1 도중 소동 공지가 뜨면 안내선이 숨는지.
7. 휴대폰 가로 화면에서 토스트가 HUD를 가리지 않는지(캡처).
