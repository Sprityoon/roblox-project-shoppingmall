# 아이디어 메모

나중에 구현 여부를 결정할 것들을 모아 둔다. 여기 있는 것은 **결정되지 않은 것**이므로 에이전트는 사용자가 채택하기 전에는 구현하지 않는다. 채택되면 [plan/tasks.md](../plan/tasks.md)로 옮기고 여기서는 상태만 바꾼다.

형식:

```
## 제목
- 상태: 대기 | 채택(T-번호) | 기각
- 제안: 누가, YYYY-MM-DD
- 내용: 무엇을, 왜
- 메모: 비용·리스크·관련 아이디어
```

## 소동 후보
- 상태: 채택 (2026-11-12. 대정전 T-108, 도망치는 쇼핑카트 T-109, 깜짝 플래시몹 T-119. 마트 대청소는 보류)
- 제안: Claude Code, 2026-11-12
- 내용: 소동마다 "하는 행동"이 달라야 번갈아 나와도 질리지 않는다. 원안의 카트 수거와 대청소는 둘 다 "가서 줍기"라 겹친다.
  1. **쇼핑몰 대정전 (1호 추천)**: 몰 전체 불이 꺼지고 손전등이 켜진다. 어둠 속에서 빛나는 배터리를 찾아 구역 차단기에 꽂으면 그 구역이 다시 밝아진다. 전부 켜면 성공. 공간 전체가 바뀌어 소동 느낌이 가장 크고, 어두워서 화이트박스 맵의 허술함이 가려지며, 진행도가 "몰이 밝아지는 것"으로 보인다. 전기실도 쓰인다. 완전한 암흑과 강한 점멸은 피한다.
  2. **도망치는 쇼핑카트 (2호 추천, 원안 변형)**: 카트가 살아서 도망 다닌다. 여럿이 몰아서 잡고, 잡은 카트를 타고 광장 보관소로 가져간다. 추격 자체가 웃기고 협동이 저절로 생긴다. 혼자면 카트가 느려진다.
  3. **깜짝 플래시몹 (짧은 소동, 90초)**: 스테이지의 MC가 동작을 외치면 3초 안에 같은 이모트를 한다. 맞춘 사람이 많을수록 게이지가 찬다. 줍기류와 전혀 다른 종류이고, 이모트와 스테이지를 다시 쓰며, 만들기가 가장 쉽다.
  4. 마트 대청소: 2번과 행동이 겹쳐 뒤로 미룬다.
- 메모: 모든 소동 공통으로 권하는 것 — 성공하면 광장에서 10초 축하를 하고 그때 광장에 있는 사람에게 보너스 코인(집결이 실제 행동이 된다), 실패해도 참여 보상(구현됨), 진행도는 숫자보다 공간 변화로 보여 주기.
