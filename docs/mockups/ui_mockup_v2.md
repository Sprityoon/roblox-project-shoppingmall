## 2. 상시 HUD 배치 (PC & 모바일 가로 공통)

```text
+-----------------------------------------------------------------------+
| [☰][💬]            (Roblox TopBar 안전 영역 48px)                     |
+-----------------------------------------------------------------------+
| [● 중앙 광장]         [  ⚡ 소동 예고 / 진행 바  ]       [C 360] [🛍️] |
| [🔋 배터리 운반 중]   (평상시에는 비워 둠)                             |
|                                                                       |
|                                                                       |
|                       (화면 중앙 40%+ 개방)                            |
|                                                                       |
|                                                                       |
|  (이동 조이스틱)                              [👋][🎉][💃][👏]  (점프) |
|   좌하단 비움                                  이모트 4종 도크   비움  |
+-----------------------------------------------------------------------+
```

1. **좌상단 — 현재 구역 알약 + 운반 상태 배지**
   - 구역이 바뀔 때 점 색과 이름만 부드럽게 변경(`복도` → `마트`).
   - `CarryService`로 물건을 들면(`Carrying ~= ""`) 바로 아래 노란 알약(`🔋 배터리 운반 중 · 차단기 앞 원으로 이동`)이 나타남.
2. **상단 중앙 — 소동 상태 배너 (상태별 자동 전환)**
   - **평상시(`idle`)**: 숨김 (시야 확보).
   - **소동 예고(`notice`, 60초)**: 주황 테두리 알약 — `⚡ 곧 소동 시작 · 쇼핑몰 대정전` + 한 줄 안내 + 남은 초 카운트다운(`00:48`).
   - **소동 진행(`active`)**: 짙은 남색 카드 + 연두 진행 바 — `⚡ 쇼핑몰 대정전 · 4 / 6 · 02:14`.
3. **우상단 — Mall Coins 알약 + 보조 버튼**
   - 고정 폭 우측 정렬 숫자(`1.2K` 축약)로 값 변할 때 흔들림 방지 + 획득 시 잠깐 확대 애니메이션.
4. **우하단 (점프 버튼 왼쪽) — 이모트 4종 도크**
   - `👋 인사`, `🎉 환호`, `💃 춤`, `👏 박수` (`44×44px` 이상, 이후 플래시몹 소동 `T-119`에서도 그대로 사용).

## 3. 소동 결과 창 (`EventResult` 모달)

```text
+--------------------------------------------+
|  소동 해결! · 6 / 6 완료          [성공 🎉] |
|  ⚡ 쇼핑몰 대정전                           |
+--------------------------------------------+
|   [ 내 기여 ]   [ 받은 코인 ]   [ 오늘 MVP ] |
|      3개          +90 C       SuperCARRY   |
+--------------------------------------------+
|  참여 +30 · 해결 성공 +60     스탬프 +1 적립! |
+--------------------------------------------+
|           [  확인하고 계속 놀기  ]           |
+--------------------------------------------+
```

- 목표 달성/종료 시 한 번만 표시(중복 모달 금지), 우상단 X / 바깥 탭 / 확인 버튼 / `Esc`·`B`로 닫기.
- 실패 시에도 `"아쉽지만 시간 종료"` 헤더 + 참여 보상(`+30 C`)을 그대로 표시.

## 4. 상점 창 (장난감 가게 · 패션 상점 · 마트)

- NPC 대화(`ProximityPrompt`)로 해당 상점 탭이 바로 열린 상태로 띄움(상점 간 탭 전환도 최대 3개).
- **상품 카드 규격**: 아이콘 + 오늘의 특가(30% 할인) 뱃지 + 상품명 + 한 줄 효과 + 상태별 단일 버튼:
  - `✓ 장착 중` / `장착` / `구매 · C 320` / `C 80 부족` (누르면 살짝 흔들리고 토스트 안내).
- **취급 품목**:
  - **🧸 장난감 가게**: 풍선(12종), 손전등 색
  - **✨ 패션 상점**: 발자취(Trail), 반짝이 효과(Aura), 칭호
  - **🥤 마트**: 한입 간식(소모품: 달리기 +20% 60초, 점프 강화 등)
