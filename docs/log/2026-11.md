## 2026-11-11 Antigravity — 반주 끊김 수정 (T-010)
- 한 일: 사용자 피드백("중간중간 반주가 뚝뚝 끊기는 구간")의 원인을 진단해 4가지를 수정.
  1. `acquireSlot` 기준을 미래 예약 시각(`fireAt`)에서 현재 믹서 시각(`mixerNow`) + 라운드 로빈(`SoundPool`)으로 변경해, 재생 중이거나 예약 대기 중인 슬롯을 덮어쓰며 `Stop()` 시키던 버그 해결.
  2. `GetWaveformAsync`로 확인한 `electric_bass` 앞 0.16s 무음 등을 `Instruments.sampleStart`로 건너뛰도록 추가.
  3. `PlaybackRegion` 칼절단 대신 `onHeartbeat`에서 80ms Soft Release 페이드아웃 후 정지하고, `block`/`pad` 게이트를 8/16스텝으로 채워 다음 화음과 자연스럽게 이어지게 개선.
  4. `LOOKAHEAD_SEC` 0.35s, `START_LEAD_SEC` 0.20s, `Play()` 직후 첫 스텝 즉시 예약, 최소 리드 `0.04s` 적용으로 프레임 지연 시 스텝 스킵 방지.
- 위치: Studio `ReplicatedStorage.Shared.Config.Instruments`, `StarterPlayerScripts.Client.Controllers.AudioController`, `docs/plan/audio-notes.md`
- 확인: 플레이 테스트에서 `Melodic_piano_1~3` 3화음과 `Melodic_electric_bass_1~2`가 슬롯 충돌 없이 라운드 로빈으로 분산 재생되고 콘솔 오류 0건 확인.
